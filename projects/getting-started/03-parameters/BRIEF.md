# Vision

Create a glowing, atmospheric noise visualization with real-time parameter control through interactive sliders.

## Aesthetic Goals
- Soft, ethereal glow with bloom effect
- Customizable color saturation and hue
- Adjustable detail levels and animation speed

## Techniques Demonstrated
- Parameter system with slider UI (Tab to toggle)
- MCP workflow for persisting slider changes to code
- Combining Noise, Blur, HSV, and Bloom operators
- Visual exploration through interactive tweaking
