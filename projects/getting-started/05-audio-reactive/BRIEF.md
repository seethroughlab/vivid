# Vision

Create a dynamic visualization that pulses, shifts, and glows in response to live audio input from your microphone.

## Aesthetic Goals
- Deep blue-to-orange color scheme that intensifies with volume
- Bass-driven scale changes for rhythmic impact
- High-frequency triggered bloom for sparkle and energy

## Techniques Demonstrated
- AudioIn for microphone capture
- Frequency analysis with BandSplit (bass, mid, high)
- Mapping audio values to visual parameters in update()
- Smoothing for controlled, musical response
