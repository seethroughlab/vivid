# Vision

Apply real-time distortion effects to live webcam video, creating a wavy, dreamlike mirror controlled by mouse movement.

## Aesthetic Goals
- Fluid, water-like displacement ripples
- Interactive distortion strength and wave size
- Cinematic polish with vignette framing

## Techniques Demonstrated
- Webcam capture as a texture source
- Displacement mapping using animated noise
- Mouse input for interactive parameter control
- Combining live video with procedural effects
