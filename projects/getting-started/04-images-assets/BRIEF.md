# Vision

Transform a static image into a polished, stylized visual with color grading, soft glow, and cinematic vignetting.

## Aesthetic Goals
- Enhanced color vibrancy with HSV adjustments
- Soft, luminous glow on highlights
- Dark vignette corners for focus and depth

## Techniques Demonstrated
- Loading images from the assets folder
- Image processing pipeline (color, bloom, vignette)
- Creating filter-style effects for photography
- Asset organization conventions
