# Vision

Create a stylized neon threshold effect with animated edges and glowing highlights using built-in operators as building blocks.

## Aesthetic Goals
- High-contrast threshold with soft edges
- Dark blue to cyan color gradient
- Intense glow creating a neon/electric feel

## Techniques Demonstrated
- Operator class pattern and lifecycle overview
- Prototyping custom effects with built-in operators
- Combining Threshold, Colorize, and Bloom for style
- Understanding when custom operators are needed
