# Vision

A complete, well-organized audio-reactive visualization combining pulsing shapes, color-shifting noise, and glowing post-effects.

## Aesthetic Goals
- Layered composition with noise background and geometric overlay
- Continuously cycling color palette through hue rotation
- Audio-responsive scaling, speed, and bloom intensity

## Techniques Demonstrated
- Modular code organization with helper functions
- ChainConfig for window and rendering settings
- Compositing multiple visual layers with blend modes
- Best practices for maintainable Vivid projects
