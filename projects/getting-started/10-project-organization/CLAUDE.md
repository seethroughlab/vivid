# Lesson 10: Project Organization

This is the final lesson in the Getting Started series. It teaches best practices for organizing Vivid projects, especially for AI-assisted development.

## Lesson Objectives

1. Understand recommended project structure
2. Learn how to write effective CLAUDE.md files
3. Configure windows with ChainConfig
4. Know best practices for maintainable projects

## Key Concepts

- **Project structure**: Consistent folder organization
- **CLAUDE.md**: Context file for AI assistance
- **ChainConfig**: Window and rendering configuration
- **Asset organization**: Logical grouping of media files

## This CLAUDE.md is an Example!

This file demonstrates the format for project CLAUDE.md files:

### What Makes a Good CLAUDE.md

1. **Brief description**: What does this project do?
2. **Current state**: What's working, what's in progress?
3. **Goals**: What are you trying to achieve?
4. **Preferences**: Any style or approach preferences?
5. **Notes**: Important context or limitations

### What to Avoid

- Don't include entire code files (Claude can read them directly)
- Don't include generic Vivid documentation
- Don't make it too long - keep it scannable
- Don't forget to update it as the project evolves
