# Vision

Create your first animated visual: a flowing, organic noise pattern that evolves continuously in real-time.

## Aesthetic Goals
- Smooth, cloud-like procedural patterns
- Gentle, hypnotic motion
- Grayscale foundation (with optional color exploration)

## Techniques Demonstrated
- Basic chain structure with setup/update pattern
- Noise operator for procedural generation
- Hot-reload workflow for instant feedback
- Parameter tuning (scale, speed, octaves)
