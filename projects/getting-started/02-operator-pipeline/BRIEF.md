# Vision

Build a colorful, flowing gradient visualization by chaining multiple operators to transform raw noise into rich, blended colors.

## Aesthetic Goals
- Deep blue to warm orange color palette
- Soft, diffused edges from blur processing
- Dreamy, painterly quality

## Techniques Demonstrated
- Connecting operators with `.input()` method
- Multi-stage processing pipeline (generate, blur, colorize)
- Using Gradient + Lookup for color mapping
- Understanding data flow direction
