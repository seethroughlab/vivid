## Release notes

### New
- Open String preset
- Slide Up preset
- Slide Down Preset
- Single layer for each articulation
- Added "Swell" (Attack) knob

## Using the instrument
To use the instrument, simply load any of the three articulations into decentsampler. The presets should automatically link within the plugin for easy modulation of articulations by switching presets.

## The Story
I was allowed to borrow this Lapsteel from a long time family friend David Long https://www.davidlongnz.com/ for demo recording
After recording some demos for my band Nine Lives Narrow, I had truely fallen in love with the instrument. I hope you find enjoyment and inspiration with this sample library.
