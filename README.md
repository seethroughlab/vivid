# VIVID

**A general-purpose creative coding platform with audio-visual parity.**

Vivid is a framework for building real-time audiovisual experiences — performances, installations, interactive art — where audio and visuals are equal peers in the same graph, driven by the same data, with the same level of expressive control.

Built in C++ with Dawn (WebGPU), designed from the ground up for LLM-assisted creative exploration.

🚧 **Coming soon.** Currently in early development (Phase 1).
