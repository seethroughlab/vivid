# Vivid 4

Vivid 4 is a reboot of Vivid as an agent-first audiovisual session environment.

This branch starts from a clean product root. The previous codebase is preserved on the
`vivid-classic` branch and tagged as `vivid-classic-final`; use it as a reference, parts bin,
and warning label, not as the architecture to renovate in place.

The first proof target is Session View:

- master BPM and time signature
- plugin-first music authoring
- clips as behavior capsules
- visual bindings as first-class session objects
- high-level agent tools before low-level graph mutation
- usability gates before runtime implementation
