# v0.1.1 Release Testing Checklist

Use this checklist to verify functionality before tagging the release.

Legend: **Mac** = macOS, **Win** = Windows, **RPi** = Raspberry Pi

---

## Platform-Specific Commands

Throughout this checklist, use the appropriate command for your platform:

| Action          | macOS/Linux            | Windows                  |
|-----------------|------------------------|--------------------------|
| Run vivid       | `./build/bin/vivid`    | `build\bin\vivid.exe`    |
| Temp file path  | `/tmp/test.png`        | `%TEMP%\test.png`        |
| List lib files  | `ls build/lib/`        | `dir build\lib\`         |
