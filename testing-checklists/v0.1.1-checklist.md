# v0.1.1 Manual Testing Checklist

This checklist contains **only tests that require human verification**. Automated tests run via `ctest` in CI.

Legend: **Mac** = macOS, **Win** = Windows, **RPi** = Raspberry Pi

---

## Automated Tests (run in CI)

The following tests are automated and run via `ctest --test-dir build -C Release`:

- **Build verification**: Version check, library existence
- **Smoke tests**: All examples run without crashing (snapshot mode)
- **Visual regression**: Snapshot comparison against reference images
- **MCP server**: JSON-RPC protocol tests (initialize, list_operators, search_docs)

To run locally: `ctest --test-dir build --output-on-failure -C Release`
