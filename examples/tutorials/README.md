# Tutorial Projects

These examples are tutorial-first artifacts: each one should produce or describe a saved project
that proves a product workflow and can later become a regression/showcase fixture.

- `mcp-native-first-project/` — ADR-0034 Golden Path A, a shader-first MCP-native creative coding
  tutorial that assumes Surge XT is installed.
- `live-shader-edit/` — ADR-0034 follow-up, a pressure test for editing a project-local shader while
  the project is running.

The curated free plugin list lives in `free-plugin-starter-list.md`. Keep tutorial dependencies
boring and explicit: Surge XT is required for the first project; other free plugins are optional
follow-up material.
