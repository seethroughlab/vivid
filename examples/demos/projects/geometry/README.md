# Geometry

A bundled visual example (**File > Open Example**). Real *vertex* geometry — a
**ShapeGrid**, **Lines**, and a wireframe **Mesh** — feeding a **Switch**, so you
flip 1-of-3 into the **Output**.

The counterpoint to `generative-fields`: where that showcases fullscreen shader
*fields*, this showcases the core's real geometry operators (ADR: "real geometry,
not screensavers"). Fully portable — no plugins, no media, no external assets.
