# Reference Graphs

This folder keeps useful graph material that should not crowd the default beta example browser.

- `audio/` - older variants, focused operator demos, and package-dependent audio patches
- `gpu/` - focused GPU operator references and hardware-dependent visual examples
- `filters/` - one-filter and shader-chain reference patches
- `media/` - movie-file and texture-loader references
- `io/` - MIDI, OSC, Syphon, and other live external I/O references
- `shader_sketches/` - WGSL sketch ports and visual experiments

These graphs are still part of the project corpus. Run them directly with `./build/vivid` or smoke
test them with `./build/test_demo_graphs reference_graphs` when validating broad coverage.
