# v0.1.1 Testing Checklist

This checklist organizes tests into three categories based on how they should be run.

Legend: **Mac** = macOS, **Win** = Windows, **RPi** = Raspberry Pi

---

# 1. CI Tests (GitHub Actions)

These tests run automatically on every push/PR. No action required.

| Test Category       | Description                                      |
|---------------------|--------------------------------------------------|
| Unit tests          | Core 2D effects, audio synthesis, network ops    |
| Integration tests   | Chain processing, operator connections           |
| Build verification  | Version check (`--version` output)               |

**CI Status:** https://github.com/seethroughlab/vivid/actions

To run locally:
```bash
# macOS/Linux
ctest --test-dir build --output-on-failure -C Release -L "unit|integration|build"

# Windows
ctest --test-dir build --output-on-failure -C Debug -L "unit|integration|build"
```
