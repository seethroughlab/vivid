# Docs Archive

This directory contains historical planning/execution artifacts that are no longer part of the active, day-to-day documentation set.

## What belongs here

- One-time execution reports
- Baseline snapshots captured before implementation
- Milestone completion evidence that is superseded by tests and roadmap status

## Active docs

Current user-facing docs remain in `docs/`. Engineering references are organized in:
- `docs/internal/` for internal specs and evaluations
- `docs/testing/` for test plans and validation protocols
- `docs/release/` for release operations/checklists
