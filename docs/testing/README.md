# Testing Docs

This folder contains test plans, manual test catalogs, and validation protocols used during development and release hardening.

These documents support engineering workflows and are separated from user-facing docs in `docs/`.

Key playback/release-hardening artifacts:

- `MOVIE-PLAYBACK-VALIDATION.md` — full manual playback validation matrix
- `MOVIE-PLAYBACK-GO-NO-GO.md` — release gate / certification checklist
- `movie-playback-runtime-gate.json` — `run_checks` payload for healthy AV-sync runtime gating
