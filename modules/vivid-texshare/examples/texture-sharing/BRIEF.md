# Vision

A colorful animated noise pattern that is shared with other applications via Syphon (macOS) or Spout (Windows), enabling real-time texture sharing between Vivid and VJ software like Resolume, VDMX, or TouchDesigner.

## Aesthetic Goals

- Smooth, flowing animated simplex noise
- Continuously shifting hue for visual interest
- Demonstrates interoperability with professional VJ software

## Techniques Demonstrated

- TextureShareOut operator for publishing textures
- Syphon/Spout cross-application texture sharing
- Animated noise generation with HueShift color grading
- Server discovery for available texture sources
