# Vision

External control of visual parameters via OSC (Open Sound Control), enabling live performance control from TouchOSC, Lemur, or Max/MSP.

## Aesthetic Goals
- Responsive visual feedback to controller input
- Real-time color and shape manipulation
- Triggerable flash effects for performance punctuation

## Techniques Demonstrated
- OscIn for receiving messages on multiple address patterns
- OscOut for sending feedback to controllers
- Mapping faders, XY pads, and buttons to visual parameters
