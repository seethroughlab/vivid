# Vision

A liquid distortion effect that warps a live webcam feed using animated noise, creating wavy, organic motion as if viewing through rippling water or heat shimmer.

## Aesthetic Goals
- Fluid, organic distortion that feels alive
- Continuous flowing motion with adjustable intensity
- Subtle vignette framing for cinematic polish

## Techniques Demonstrated
- Webcam input combined with procedural Noise generator
- Displace operator using noise as a displacement map
- Mouse-driven parameter control for strength and scale
- Vignette post-processing for visual finish
