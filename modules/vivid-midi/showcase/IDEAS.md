# Showcase Ideas for vivid-midi

Future showcase projects that demonstrate the full creative potential of this module.

## Proposed Projects

### MIDI Visualizer
**Status:** Proposed
**Complexity:** Medium
**Description:** Real-time visualization of MIDI input with note trails, velocity mapping, and channel colors.
**Key Features:**
- Piano roll display with falling notes
- Velocity-to-color/size mapping
- Multi-channel visualization with routing

### Controller Mapper
**Status:** Proposed
**Complexity:** Medium
**Description:** Visual MIDI learn interface for mapping controllers to any chain parameter.
**Key Features:**
- Click-to-learn parameter binding
- CC curve adjustment (linear, log, exp)
- Save/load controller profiles

### Generative MIDI Sequencer
**Status:** Proposed
**Complexity:** Complex
**Description:** Euclidean/algorithmic MIDI sequencer with visual feedback.
**Key Features:**
- Euclidean rhythm generator
- Probability and humanization controls
- Scale/chord constraint modes
