# Vision

A visual step sequencer that sends MIDI notes to external synthesizers, with animated piano keys showing the current pattern.

## Aesthetic Goals
- Glowing piano-style key visualization
- Color cycling based on note position
- Tempo and velocity controlled by mouse movement

## Techniques Demonstrated
- MidiOut for sending to hardware/software synths
- Clock and Sequencer for rhythmic patterns
- Visual-to-hardware synchronization
