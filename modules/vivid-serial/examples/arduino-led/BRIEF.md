# Vision

Physical computing bridge connecting Vivid's LFO output to Arduino-controlled LED brightness via serial communication.

## Aesthetic Goals
- Smooth pulsing LED synchronized to Vivid's LFO
- Real-world manifestation of digital oscillator
- Simple hardware integration pattern

## Techniques Demonstrated
- SerialOut for sending data to microcontrollers
- LFO value mapping to PWM range (0-255)
- Cross-platform serial port configuration
