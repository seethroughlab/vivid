# Showcase Ideas for vivid-imgui

Future showcase projects that demonstrate the full creative potential of this module.

## Proposed Projects

### Visual Patch Editor
**Status:** Proposed
**Complexity:** Complex
**Description:** Node-based visual programming interface for building Vivid chains.
**Key Features:**
- Drag-and-drop operator nodes
- Visual connection wires between operators
- Live parameter editing with immediate preview

### Performance Dashboard
**Status:** Proposed
**Complexity:** Medium
**Description:** Real-time performance monitoring with GPU/CPU metrics and frame timing.
**Key Features:**
- Frame time graphs and statistics
- Memory usage tracking
- Operator execution profiling

### Preset Manager
**Status:** Proposed
**Complexity:** Simple
**Description:** Save, load, and organize parameter presets with smooth morphing between states.
**Key Features:**
- Preset browser with thumbnails
- A/B comparison mode
- Interpolated transitions between presets
