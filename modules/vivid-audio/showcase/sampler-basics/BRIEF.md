# Vision

Three sampler modes demonstrating chromatic playback, drum triggering, and multi-zone velocity-layered instruments with a visual piano keyboard.

## Aesthetic Goals
- On-screen piano keyboard visualization
- Keys highlight when played
- Clean interface showing active voice count
- Radial gradient background for depth

## Techniques Demonstrated
- Sampler for chromatic single-sample playback
- SamplePlayer for drum/effect triggering from banks
- MultiSampler for velocity-layered multi-zone instruments
- Computer keyboard mapped to MIDI note input
