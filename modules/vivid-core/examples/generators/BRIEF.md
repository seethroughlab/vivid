# Vision

A gallery of core visual generators: solid colors, gradients, animated ramps, and SDF shapes arranged in a 2x3 grid with LFO modulation.

## Aesthetic Goals
- Clean presentation of fundamental building blocks
- Smooth LFO-driven animation
- Variety of shape primitives (circle, rectangle, polygon)
- HSV color cycling for visual interest

## Techniques Demonstrated
- SolidColor, Gradient, and Ramp generators
- Shape operator with Ellipse, Rectangle, and Polygon types
- LFO operator for oscillating values
- Parameter binding with range mapping
- Canvas grid layout with FitMode control
