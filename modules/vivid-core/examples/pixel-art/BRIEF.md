# Vision

Retro pixel art aesthetic created through pixelation and color quantization, transforming images into chunky low-res graphics.

## Aesthetic Goals
- Blocky mosaic pixels with sharp edges
- Limited color palette posterization
- Classic 8-bit video game aesthetic
- Fixed 640x480 retro window size

## Techniques Demonstrated
- Pixelate for block-based sampling
- Quantize for color level reduction
- Combined pipeline for authentic pixel art
- Side-by-side comparison of effects
- Animated parameter variation
