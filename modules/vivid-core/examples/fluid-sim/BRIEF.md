# Vision

Interactive fluid canvas where mouse strokes create flowing rainbow colors that swirl, merge, and fade with realistic fluid dynamics.

## Aesthetic Goals
- Dark ambient background with vibrant flowing colors
- Organic turbulent swirls and vortices
- Ethereal bloom glow on bright areas
- Smooth continuous color cycling through rainbow

## Techniques Demonstrated
- FluidSim operator for GPU Navier-Stokes simulation
- Force and dye injection via mouse input
- HSV color cycling for rainbow effect
- Bloom post-processing for glow
- Keyboard input for fullscreen and clear
