# Vision

An interactive test pattern demonstrating how 4:3 content scales to fit different window aspect ratios using various display modes.

## Aesthetic Goals
- Clear geometric reference markers
- Colored corner indicators for quick alignment checks
- Center circle for distortion detection
- Grid overlay for aspect ratio visualization

## Techniques Demonstrated
- DisplayMode options: Stretch, Fit, Fill, FillHorizontal, FillVertical
- Render resolution vs window size separation
- Keyboard input for mode switching
- Visual indicators for content bounds
