# Vision

Interactive circle that responds to mouse dragging, clicking, and keyboard input, demonstrating the full range of user input capabilities.

## Aesthetic Goals
- Immediate visual feedback to user actions
- Clean dark background with bright interactive element
- Real-time coordinate and state display

## Techniques Demonstrated
- Mouse position in normalized and pixel coordinates
- Mouse button state (pressed, held, released)
- Keyboard input with modifier keys (Shift, Ctrl, Alt)
- Drag interaction pattern
- UI overlay with real-time status display
