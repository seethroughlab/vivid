# Vision

An animated canvas showcasing HTML5-style procedural drawing with bouncing balls, rotating squares, radiating lines, and gradient fills.

## Aesthetic Goals
- Playful geometric animation with color cycling
- Dark blue background with vibrant accents
- Smooth continuous motion with pulsing rhythms

## Techniques Demonstrated
- Canvas API for procedural 2D drawing
- Linear and radial gradients
- Transform state management (save/restore)
- Clipping regions for masked effects
- HSV color shifting for animation
