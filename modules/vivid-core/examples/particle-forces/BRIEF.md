# Vision

Flowing particle streams driven by curl noise forces, creating organic swirling patterns with subtle upward drift.

## Aesthetic Goals
- Fluid-like organic motion
- Cyan-to-magenta color gradient over particle lifetime
- Dense particle field with smooth turbulence
- Dark atmospheric background

## Techniques Demonstrated
- ParticleSystem with CPU simulation
- CurlNoiseForce for turbulent flow fields
- DragForce for velocity damping
- GravityForce for directional drift
- Modular force stack API
