# Vision

A video color correction laboratory displaying multiple grading techniques side-by-side, from hue shifts to posterization to cinematic tone mapping.

## Aesthetic Goals
- Professional color correction workflow visualization
- Dramatic mood shifts through color manipulation
- Film-quality tone curves and exposure control

## Techniques Demonstrated
- HSV adjustment for hue, saturation, and value
- Brightness and contrast control
- Quantize for color palette reduction
- Level for gamma and range mapping
- ToneMap with Reinhard, ACES, and Filmic curves
