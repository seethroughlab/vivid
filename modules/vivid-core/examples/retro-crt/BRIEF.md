# Vision

Authentic CRT television simulation with scanlines, screen curvature, dithering, and chromatic aberration over a pulsing star shape.

## Aesthetic Goals
- Vintage CRT monitor aesthetic
- Visible scanline raster effect
- Screen edge curvature and vignetting
- Low-resolution dithered colors
- Hue cycling animation

## Techniques Demonstrated
- Downsample for low-resolution rendering
- Dither with Bayer pattern for retro colors
- Scanlines operator for raster effect
- CRTEffect for curvature, vignette, and chromatic aberration
- Mouse control for real-time parameter tweaking
