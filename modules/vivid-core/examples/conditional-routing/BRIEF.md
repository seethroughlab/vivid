# Vision

A time-based visual selector that smoothly crossfades between three distinct looks: flowing noise, radial gradients, and animated shapes.

## Aesthetic Goals
- Clean transitions between contrasting visual styles
- Automatic cycling creates meditative rhythm
- Soft crossfade blending prevents jarring cuts

## Techniques Demonstrated
- Switch operator for texture routing
- Math operator with Fract for sawtooth timing
- Logic operators for comparison checks
- Time-based automatic selection cycling
