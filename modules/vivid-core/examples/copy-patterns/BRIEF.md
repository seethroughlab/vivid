# Vision

Geometric pattern generator creating trails, radial arrays, and grids from simple shapes, with bloom effects for luminous results.

## Aesthetic Goals
- Glowing orange spiral trails
- Cyan rotating petal arrangements
- Pulsing green grid arrays
- Dark background with additive glow

## Techniques Demonstrated
- Copy operator in Linear mode (trail effects)
- Copy operator in Radial mode (circular arrays)
- Copy operator in Grid mode (tiled patterns)
- Per-copy rotation, scale, and opacity falloff
- Mouse-interactive parameter control
