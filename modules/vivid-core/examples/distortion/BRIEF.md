# Vision

Video warping laboratory showing chromatic aberration, barrel curvature, edge detection, and noise-based displacement over a grid overlay.

## Aesthetic Goals
- RGB channel separation for prismatic edges
- CRT-style screen curvature
- High-contrast edge outlines
- Organic flowing displacement waves

## Techniques Demonstrated
- ChromaticAberration for RGB separation
- BarrelDistortion for lens curvature
- Edge detection (Sobel operator)
- Displace with animated noise map
- Grid overlay for distortion visualization
