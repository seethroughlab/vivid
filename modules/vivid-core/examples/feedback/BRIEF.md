# Vision

Hypnotic spiral trails created through feedback loops, where each frame blends with a zoomed and rotated version of the previous frame.

## Aesthetic Goals
- Infinite recursive depth illusion
- Slow spiral rotation and zoom drift
- Rainbow color wash over feedback trails
- Organic particle-like noise seeds

## Techniques Demonstrated
- Feedback operator for temporal recursion
- Decay, zoom, and rotation per frame
- Mouse control for real-time parameter adjustment
- State preservation across hot-reload
- Debug value monitoring
