# Vision

Binary thresholding applied to video, converting grayscale to high-contrast black and white with various cutoff points and softness levels.

## Aesthetic Goals
- Stark black and white silhouettes
- Animated threshold revealing hidden detail
- Soft edge posterization effects
- Inverted negative versions

## Techniques Demonstrated
- Threshold operator for binary conversion
- Adjustable threshold level (low, mid, high)
- Softness parameter for gradient edges
- Invert option for negative effect
- Grid comparison of different settings
