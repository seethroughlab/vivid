# Vision

Interactive trigger demonstration where keyboard presses fire decay envelopes that drive visual parameters like size, color, and bloom intensity.

## Aesthetic Goals
- Responsive visual feedback to user input
- Different decay rates for punchy vs sustained response
- Color-coded trigger indicators (red, green, blue)
- Real-time value readout overlay

## Techniques Demonstrated
- Trigger operator with configurable decay rates
- Attack parameter for slow ramp-up effects
- Keyboard event handling for trigger firing
- Parameter binding from trigger values
- Multiple triggers with independent timing
