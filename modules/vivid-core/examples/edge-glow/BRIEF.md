# Vision

Neon outline effect that extracts edges from an image and adds pulsing, color-cycling glow for a cyberpunk aesthetic.

## Aesthetic Goals
- Bright neon contours over darkened imagery
- Rainbow hue cycling through the color spectrum
- Pulsing bloom intensity for breathing effect
- High-contrast silhouette style

## Techniques Demonstrated
- Edge detection for contour extraction
- SolidColor multiplication for edge colorization
- Bloom with high intensity for glow halos
- Composite with Add mode for luminous overlay
- HSV-to-RGB color cycling animation
