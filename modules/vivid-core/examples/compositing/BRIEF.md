# Vision

Layered texture combinations demonstrating classic blend modes, with animated noise and shapes mixed through Over, Add, Multiply, and Screen operations.

## Aesthetic Goals
- Rich texture layering with visible mode differences
- Flowing organic motion from animated gradients and noise
- Real-time parameter binding visualization

## Techniques Demonstrated
- Composite operator with multiple blend modes
- LFO for oscillating parameter values
- Math operator for value remapping
- Logic operator for conditional behavior
- Trackable bindings (visible in chain visualizer)
