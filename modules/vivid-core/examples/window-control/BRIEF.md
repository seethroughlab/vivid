# Vision

An interactive demo for window management showing fullscreen toggle, VSync control, preset sizes, and real-time timing information.

## Aesthetic Goals
- Clean information overlay on animated noise
- Real-time metrics display (FPS, frame count, time)
- Clear keyboard control hints

## Techniques Demonstrated
- Window resize and fullscreen control
- VSync toggle for frame rate management
- Preset window size selection
- Time functions: time(), realTime(), dt(), realDt()
- Frame counter and resize detection
- Window positioning API
