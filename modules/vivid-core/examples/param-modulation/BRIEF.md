# Vision

Three animated shapes demonstrating different parameter binding approaches: operator-driven, lambda with range mapping, and direct lambda control.

## Aesthetic Goals
- Clear visual distinction between binding methods
- Smooth oscillating motion from LFO
- Mouse-responsive size changes
- Continuous rotation animation

## Techniques Demonstrated
- bind(operator) for trackable LFO connections
- bind(lambda, min, max) for range-mapped values
- bindDirect(lambda) for full control
- Orange color indicates trackable bindings in visualizer
- Cyan indicates lambda bindings
