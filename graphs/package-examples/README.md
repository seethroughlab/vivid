# Package Examples

This category is reserved for package-centric examples.

Current core repo guidance:
- Keep package-owned graphs in their package repos (for example `vivid-wavetable`, `vivid-drums`, `vivid-plexus`, `vivid-sequencers`, `vivid-3d`, `vivid-glitch`).
- Link/install those packages and open their graph files from their own `graphs/` folders.
